# Country packs

Everything that differs by country lives here as settings, not code. See [docs/07](../../docs/07_Global_Design_and_Country_Packs.md).

**Rules:** a pack can make things stricter, but can never switch off a safety rule. Unreviewed packs are labelled, and refused in production. Never invent clinical data, services or contacts.

**Status:** stubs only. No code until requested.

| Folder | Use |
|---|---|
| `_template/` | Copy this to add a country |
| `ae-abu-dhabi/` | First reference pack, in English, Arabic and Hindi, pending clinical and legal review |
| `in-india/` | Illustrative second pack, in Hindi and English, not reviewed |
