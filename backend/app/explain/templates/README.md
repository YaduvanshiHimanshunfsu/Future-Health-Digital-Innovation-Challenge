# Fallback templates

Approved text per scenario × language × level: `<scenario>.<lang>.<level>.j2`.

**Rules:** Used when the LLM fails or is off. Must pass all validators. Numbers injected by code. T1 scenarios at Simple level come first.

**Status:** stubs only. No code until requested.
